# ADR-004: Separación entre identidades, entrants y resultados

Estado: aceptada para Misión 01. Fecha: 2026-10-16.

## Contexto

Una persona no equivale a un entrant: un equipo puede reunir varias personas, un torneo puede incluir varios juegos y los tags cambian.

## Decisión

Separar players, tournament_participants, event_entrants, entrant_members, sets y set_sides. Conservar tag_snapshot por inscripción y aliases históricos.

## Consecuencias

Se agrega tournament_participants a las tablas solicitadas. El tamaño del equipo se define por evento y se comprueba al commit; DQ y BYE son estados explícitos. DQ doble y sets con más de dos lados requieren una extensión posterior.

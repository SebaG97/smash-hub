# ADR-001: Monorepo y arquitectura modular

Estado: aceptada para Misión 01. Fecha: 2026-10-16.

## Contexto

La fundación necesita consistencia y despliegues comprensibles, sin la operación de microservicios.

## Decisión

Mantener Next.js y FastAPI en apps/web y apps/api, con infraestructura y documentación compartidas. Los módulos del backend pertenecen al mismo proceso.

## Consecuencias

Se permite desplegar web y API por separado; los cambios de contrato se revisan juntos. No se introducen Redis, Kubernetes ni workers permanentes.

# ADR-005: Estrategia de integraciones externas

Estado: aceptada para Misión 01. Fecha: 2026-10-16.

## Contexto

Reimportar un set no debe duplicarlo y la procedencia debe poder rastrearse sin acoplar el dominio a start.gg.

## Decisión

Usar UUID internos y referencias externas textuales, con unicidad fuente/tipo/id y destinos con FK. Reservar import_jobs con clave idempotente y contratos Protocol.

## Consecuencias

El importador futuro hará upserts transaccionales y reconciliación de identidades, conservará timestamps y hash opcional. No se guardan tokens ni se implementan llamadas externas en esta misión.

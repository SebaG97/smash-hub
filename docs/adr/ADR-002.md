# ADR-002: PostgreSQL y modelo multi-comunidad/multi-juego

Estado: aceptada para Misión 01. Fecha: 2026-10-16.

## Contexto

El primer caso de uso es Paraguay/SSBU, pero no debe convertirse en una restricción del dominio.

## Decisión

Usar PostgreSQL, UUID, timestamps con zona horaria, Alembic y SQLAlchemy 2. Asociar juegos por evento y comunidades mediante community_games.

## Consecuencias

Los tests de integridad deben usar PostgreSQL real. FKs compuestas y triggers cubren relaciones que un check de una sola fila no puede validar.
